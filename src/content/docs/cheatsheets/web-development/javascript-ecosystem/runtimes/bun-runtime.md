---
title: "Bun runtime"
---

All-in-one JavaScript runtime and ecosystem toolkit written in Rust (migrated from Zig) and powered by Apple's JavaScriptCore engine.

## Architecture facts

- **Engine:** Apple's JavaScriptCore (JSC).
- **Implementation language:** Rust (migrated from Zig).
- **Scope:** Combines runtime, package manager, test runner, and bundler into a single toolchain.
