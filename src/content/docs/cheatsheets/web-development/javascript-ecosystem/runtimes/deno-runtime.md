---
title: "Deno runtime"
---

JavaScript and TypeScript runtime written in Rust and backed by `rusty_v8` bindings to Google's V8 engine.

> **Caution:** Deno runtime is being phased out (2020–2027), with development and maintenance ending around October 2027. No further coverage is maintained for this note.

## Architecture facts

- **Engine:** Google V8 through `rusty_v8` Rust bindings.
- **Implementation language:** Rust.
- **Lifecycle status:** Deprecated; end of maintenance scheduled around October 2027.
